# PROJECT_STATUS 追記テンプレート

Swift ファイルを変更したら、`PROJECT_STATUS.md` に次の形で追記する。

```md
### YYYY-MM-DD (追記N)
変更ファイル: ファイルA, ファイルB, PROJECT_STATUS.md
実装内容: 何をどう変えたかを 1〜3 文で要約
影響範囲: どの画面・機能・データに影響するか
実機確認: 実施済み / 未実施。端末名や待ち状態も書く
次にやること: 1) ... 2) ... 3) ...
```

## 書き方の要点

- 変更ファイルは相対パスで列挙する。
- 実装内容は、ユーザー価値と技術的変更点の両方が分かるように短く書く。
- 影響範囲には「見た目だけ」か「保存ロジックを含むか」を明記する。
- 実機確認が未実施なら、誰待ちか、どの端末待ちかを書く。
- 次にやることは、次回セッションでそのまま再開できる粒度にする。
